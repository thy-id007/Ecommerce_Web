# Simple Shop – React E-Commerce Practice

Practical exercises: Shopping Cart, Checkout, Order Confirmation and E-Commerce Database Design (ERD).

## Run locally
```bash
npm install
npm run dev
```

## Features
- Product list (Laptop, Mouse, Keyboard, Monitor) with **Add to Cart**
- Shopping Cart: view, update qty, remove, subtotal & grand total, Proceed to Checkout
- Checkout form with validation, shipping method, order summary, Place Order
- Order Confirmation (Order ID `ORD-0001`, customer, date, products, total, status Pending)
- Database design: [database/ERD.md](database/ERD.md) and [database/schema.sql](database/schema.sql)

Deployed automatically to GitHub Pages via GitHub Actions.
